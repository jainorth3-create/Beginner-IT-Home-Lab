# Beginner-IT-Home-Lab
A beginner-friendly virtualized IT home lab built with Oracle VirtualBox to practice real-world IT, networking, operating system, and system administration skills.

Project Overview
The goal of this project is to create a small virtual IT environment using virtual machines.

This lab provides a safe environment to practice:

Operating system installation
Virtualization
IP addressing
Networking
Linux administration
Windows administration
System troubleshooting
Basic server/client communication
IT documentation
